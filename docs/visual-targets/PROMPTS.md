The runner is a sporty 13-year-old in a sleek glowing visor helmet, neon-trimmed wetsuit-like running suit and chunky sneakers with light strips, mid-stride, seen from behind. On the LEFT edge of the screen, a tall vertical 3D number-line ruler standing beside the track with integer ticks from −6 to +8, bold labels, the 0 tick glowing cyan, a glowing marker at the runner's height and a pulsing target bracket at +3. Hebrew right-to-left HUD overlay in a clean bold game font: top-right a level name panel "שלב 1 · קו המים" with small progress dots; top-center "רצף 4" and a "×2" multiplier and a score; a huge glowing signed number "0" floating above the runner; a small chip "מנהרה: +3" next to the ruler's target bracket; bottom row of round buttons (ghost hint "רוח רפאים", pause, mute). Vibrant, high-contrast, bloom, particles, motion blur speed lines, AAA indie game look like Thumper, Audiosurf and Beat Saber. It must look like an exciting game a 13-year-old wants to play, not an educational worksheet.
